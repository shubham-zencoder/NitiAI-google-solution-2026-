# NitiAI 🇮🇳
### Your AI-Powered Assistant for Jobs, Loans & Healthcare

NitiAI is a React-based AI assistance platform built for the **Google Solution Challenge 2026**. It brings three practical support areas—employment, access to financial schemes, and healthcare information—into one simple interface.

The application uses **Google Gemini** to provide conversational assistance through dedicated, domain-specific prompts. Users can choose a module, interact with its assistant, and switch between English and Hindi.

## Overview

Access to reliable information about employment, government financial schemes, and healthcare services can be difficult to navigate. NitiAI aims to make these areas easier to explore through a conversational, bilingual interface.

Instead of using one general-purpose chatbot for every topic, NitiAI provides three focused assistants. Each assistant uses its own system prompt to guide responses and keep conversations relevant to the selected domain.

**The goal:** make useful information and practical next steps easier to access through an approachable AI interface.

## Key Features

- **Three focused AI assistants:** Separate experiences for jobs, loans, and healthcare.
- **English and Hindi interface:** Users can switch the assistant's response language using the language toggle.
- **Gemini-powered conversations:** Sends user messages and conversation context to the Google Gemini API.
- **Contextual chat history:** Maintains conversation history during the active module session.
- **Automatic welcome message:** Each module starts with a short greeting generated by the selected assistant.
- **Simple, responsive interface:** Module cards, chat screens, message bubbles, and loading feedback.
- **Domain-specific guidance:** Dedicated prompts define each assistant's role, areas of support, and response guidelines.

## Application Modules

### 1. Jobs Assistant 💼

Supports users exploring employment and career development.

Capabilities include:
- Identifying job roles based on education, skills, experience, and location.
- Guiding users through resume creation by collecting relevant details.
- Providing interview preparation and mock question-and-answer practice.
- Identifying skill gaps and suggesting learning resources.
- Directing users to relevant employment resources, including the National Career Service (NCS) portal.

### 2. Loans Assistant 💰

Helps users understand selected Indian government loan and financial assistance schemes.

The configured assistant prompt covers:
- **Pradhan Mantri Mudra Yojana (PMMY)**
- **PM SVANidhi**
- **Kisan Credit Card**
- **Stand-Up India**
- **NABARD rural loan programmes**
- **National SC/ST/OBC Finance Corporations**
- **Education loans under the CSIS scheme**
- **Jan Samarth Portal**

It is instructed to ask about the purpose of the loan, income, occupation, location, and Aadhaar/PAN availability. It can explain scheme-related eligibility considerations, commonly required documents, and where users may apply.

### 3. Healthcare Assistant 🏥

Provides general healthcare information and guidance on accessing public healthcare services.

Configured areas include:
- Understanding symptoms and considering appropriate next steps (not medical diagnosis).
- Finding information about PHCs, CHCs, government hospitals, CGHS, and ESIC.
- Ayushman Bharat PM-JAY eligibility and application guidance.
- Maternal and child healthcare programmes, including JSY, JSSK, and RBSK.
- Mental health support resources and helpline information.

**Healthcare disclaimer:** NitiAI is not a medical professional and does not provide a medical diagnosis or replace consultation with a qualified doctor. For emergencies, users should contact local emergency services. The healthcare prompt specifically directs users with serious symptoms such as chest pain, breathing difficulty, or unconsciousness to call **108**.

## How It Works

The application follows a straightforward frontend-to-Gemini request flow:

1. **Module selection:** The user selects Jobs, Loans, or Healthcare from the home page.
2. **Prompt selection:** The selected page passes its corresponding system prompt to the shared chat component.
3. **Welcome message:** The chat component sends an initial greeting to Gemini.
4. **User interaction:** The user submits a question through the chat input.
5. **Request construction:** The Gemini service combines the conversation history, new message, and module-specific system prompt.
6. **AI response:** The service sends a request to the Gemini `generateContent` endpoint.
7. **Conversation update:** The assistant response is displayed, and the conversation history is updated for subsequent requests.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (LTS version recommended)
- npm
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd NitiAI-google-solution-2026
```

Replace the repository URL with the actual GitHub repository URL.

### 2. Install dependencies

```bash
npm install
```

### 3. Configure the Gemini API key

Create a `.env` file in the project root and add:

```env
REACT_APP_GEMINI_API_KEY=your_gemini_api_key
```

Optionally, specify a Gemini model:

```env
REACT_APP_GEMINI_MODEL=gemini-2.5-flash-lite
```

If `REACT_APP_GEMINI_MODEL` is not provided, the application uses `gemini-2.5-flash-lite` by default.

### 4. Start the development server

```bash
npm start
```

Open the application at:

```text
http://localhost:3000
```

The development server reloads when you make changes to the source files.

## Environment Configuration

| Variable | Required | Description |
|---|---|---|
| `REACT_APP_GEMINI_API_KEY` | Yes | API key used for Gemini requests. |
| `REACT_APP_GEMINI_MODEL` | No | Gemini model name; defaults to `gemini-2.5-flash-lite`. |

**API key security:** This project currently calls Gemini directly from the React frontend and reads the key through a `REACT_APP_` environment variable. In Create React App, such variables are included in the browser bundle and are not secret. This setup is suitable only for a controlled prototype with appropriate key restrictions and usage monitoring. For production, move Gemini calls to a backend or serverless function, keep the key in server-side environment variables, and add suitable rate limiting and abuse protection. Never commit `.env` or a real API key to Git.

## Deployment

The repository includes a Firebase Hosting configuration. It serves the production files from the `build` directory and rewrites incoming routes to `index.html`, which supports the application's client-side routing.

To deploy:

1. Create or select a Firebase project.
2. Install and configure the Firebase CLI.
3. Authenticate with Firebase and select the intended project.
4. Build the application:

   ```bash
   npm run build
   ```

5. Deploy the hosting build:

   ```bash
   firebase deploy --only hosting
   ```

Make sure the Gemini API configuration is handled securely before deploying. A frontend environment variable does not protect an API key from being inspected in the browser bundle.

## Important Notes and Limitations

- **AI-generated information:** Responses are generated by Gemini and may be incomplete or inaccurate. Users should verify important information with official government portals, banks, or qualified professionals.
- **No live job search integration:** The current code provides career guidance and directs users to job resources; it does not implement a live job listings API.
- **No loan application integration:** The Loans Assistant explains schemes and application considerations; it does not submit applications, check a user's live eligibility, or approve loans.
- **No clinical diagnosis:** The Healthcare Assistant provides general information and access guidance, not diagnosis or treatment.
- **No dedicated database in this codebase:** Conversation history is maintained in React component state for the active chat session. The inspected project does not implement persistent user accounts or server-side chat storage.
- **API availability:** Chat functionality depends on a valid Gemini API key, model access, network connectivity, and applicable API quotas.
- **Language behavior:** The interface offers English and Hindi selection. The selected language changes the initial greeting, while the system prompts instruct the assistant to respond in the language used by the user.
